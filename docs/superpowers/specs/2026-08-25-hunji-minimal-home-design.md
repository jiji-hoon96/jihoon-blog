# 훈지 미니멀 홈 디자인

## 목적

블로그의 브랜드와 정보 구조를 `훈지`라는 두 글자에 맞춰 최소화한다. 별도의 로고 심벌과 About 페이지를 두지 않고, 홈 상단의 짧은 가치관 에세이와 최근 글 목록만으로 이지훈의 생각과 작업을 보여준다.

이 디자인은 기존 Quiet Authority의 글 중심 원칙을 유지하면서, 대표 글, 관심사 경로, 카테고리 바로가기, 설명문처럼 홈에서 필수적이지 않은 요소를 제거한다.

## 승인된 브랜드

- 워드마크는 `훈지` 두 글자만 사용한다.
- 지훈을 뒤집은 이름 자체가 관점 전환이라는 의미를 담으므로 별도의 심벌을 만들지 않는다.
- 헤더와 favicon 모두 `훈지`를 사용한다.
- 글꼴은 Wanted Sans Bold를 사용한다.
- 테두리, 배경 도형, 장식, 브랜드 전용 색상을 추가하지 않는다.
- 워드마크 색상은 본문색과 같고 다크 모드에서는 본문색과 함께 반전한다.
- favicon은 16px에서 두 글자가 완벽히 읽히는 것보다 `훈지`의 두 덩어리가 분리된 실루엣으로 인식되는 것을 목표로 한다.

## 홈 정보 구조

홈은 아래 순서만 가진다.

1. `훈지` 워드마크와 필수 유틸리티가 있는 헤더
2. 가치관을 설명하는 네 문단
3. 최근 글 다섯 편
4. 모든 글 링크
5. 외부 링크만 있는 푸터

대표 글, 카테고리, 글 설명, 읽는 시간, 인기 글, 통계, 카드, 별도 자기소개 제목은 표시하지 않는다.

## 헤더

- 왼쪽에는 `훈지` 워드마크만 둔다.
- 오른쪽에는 글 목록, 검색, 언어 선택, 테마 전환만 둔다.
- About 링크를 제거한다.
- 데스크톱과 모바일 모두 한 줄 높이를 유지한다.
- 유틸리티는 기존 접근 가능한 이름과 동작을 유지하되 시각적으로 간결하게 표현한다.

## 홈 가치관 문장

한국어 원문은 다음 네 문단으로 고정한다.

> 독특한 이름을 가진다고 독특한 사람이 되는 것은 아니라고 생각한다. 내가 더 깊이 생각하고 더 나은 것을 만드는 사람이 된다면, 내가 남기는 것들도 자연스럽게 나만의 것이 될 것이다.
>
> 지훈을 뒤집어 훈지라고 부르기 시작한 것도 그런 생각에서였다. 익숙한 생각을 조금만 뒤집어도 다른 질문과 관점이 생긴다. 소프트웨어를 만들 때도 기술보다 먼저 사용자가 겪는 문제를 보고, 당연해 보이는 선택을 다시 묻고, 판단의 이유를 남기려고 한다.
>
> 좋은 소프트웨어는 복잡한 코드를 능숙하게 다루는 데서 끝나지 않는다. 문제를 함께 이해할 수 있는 언어를 만들고, 실패를 관찰할 수 있게 하며, 다음 사람이 더 나은 판단을 할 수 있도록 맥락을 남기는 일이라고 믿는다.
>
> 이곳에는 그렇게 다르게 보고, 만들고, 다시 생각한 것들을 기록한다. 글을 쓰는 일 역시 알고 있는 것을 정리하는 것보다, 내가 무엇을 모르고 있었는지 발견하는 과정에 가깝다.

첫 문단은 나머지 문단보다 한 단계 큰 Bold로 표시한다. 나머지는 일반 본문 크기와 충분한 행간을 사용한다. 별도 제목, 라벨, 프로필 사진은 두지 않는다.

지원하는 모든 로케일에 같은 의미의 번역을 제공한다. `훈지`라는 고유 이름은 번역하지 않는다.

## 최근 글

- 현재 로케일에서 발행된 글을 날짜 내림차순으로 정렬한다.
- 가장 최근 글 다섯 편만 표시한다.
- 각 행에는 제목과 발행일만 표시한다.
- 제목은 글로 연결하고 행 전체를 클릭 가능한 영역으로 유지한다.
- 목록 아래에는 로케일별 `모든 글` 링크를 둔다.
- 대표 글과 수동 큐레이션 키는 사용하지 않는다.

## About 제거

- 전역 내비게이션에서 About 링크를 제거한다.
- 기존 `/{lang}/about` URL은 해당 로케일의 홈으로 영구 리다이렉트한다.
- 사이트맵과 구조화 데이터에서 독립된 About 페이지를 제거한다.
- 사람과 저자에 대한 구조화 데이터는 홈의 `WebSite` 및 `Person` 엔티티에 유지한다.
- 외부에 이미 공유된 About URL은 리다이렉트로 보존한다.

## 푸터

- 연도와 저작권 문구를 표시하지 않는다.
- GitHub, LinkedIn, RSS 링크만 둔다.
- Email 링크와 별도의 브랜드 문장을 제거한다.
- 홈과 글 페이지에서 동일한 푸터를 사용한다.

## 레이아웃과 시각 규칙

- 배경은 현재 구현의 흰색 canvas를 유지한다.
- 본문색, 보조색, divider는 현재 뉴트럴 토큰을 재사용한다.
- 브랜드 전용 accent 색상을 추가하지 않는다.
- 데스크톱은 현재 840px 사이트 폭을 유지한다.
- 가치관 본문은 읽기 편한 단일 열로 표시한다.
- 모바일은 24px 좌우 여백을 기준으로 한다.
- 카드, 그림자, gradient, 큰 radius, 장식 아이콘은 사용하지 않는다.

## 다국어와 접근성

- 가치관 네 문단, `글`, `모든 글` 문자열을 모든 지원 로케일에 제공한다.
- 워드마크 `훈지`에는 홈 링크와 명확한 접근 가능한 이름을 제공한다.
- favicon과 워드마크가 텍스트 대비 기준을 만족하도록 light와 dark 자산을 검증한다.
- 검색, 언어 선택, 테마 전환의 키보드 접근성과 기존 aria-label을 유지한다.

## 구현 범위

- Header의 브랜드 및 내비게이션 단순화
- Home의 가치관 문장과 최신 글 다섯 편 렌더링
- About 리다이렉트 및 사이트맵 정리
- Footer 단순화
- `훈지` favicon과 app icon 교체
- 로케일 dictionary 확장
- 홈 인덱스와 로케일 동작에 대한 테스트 갱신

## 비목표

- 글 상세 페이지의 본문 디자인 변경
- 글 목록 페이지의 카테고리 탐색 제거
- 새로운 색상 체계나 글꼴 도입
- 프로젝트, 경력, 기술 스택 섹션 추가
- 새로운 애니메이션이나 인터랙션 추가

## 검증 기준

- 첫 화면에서 `훈지`와 가치관 문장이 글 목록보다 먼저 보인다.
- 홈에는 가치관 네 문단과 최근 글 다섯 편 외의 콘텐츠 모듈이 없다.
- 모바일 390px에서도 수평 스크롤과 텍스트 겹침이 없다.
- 16px favicon에서 두 글자의 실루엣이 분리된다.
- About URL이 로케일 홈으로 리다이렉트된다.
- 모든 지원 로케일에서 홈이 정적으로 생성되고 번역 키 누락이 없다.
- 기존 검색, 언어 선택, 테마 전환, 글 목록 링크가 계속 동작한다.
