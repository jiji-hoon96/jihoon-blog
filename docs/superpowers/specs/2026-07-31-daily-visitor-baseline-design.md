# 날짜별 방문자 기본값 설계

## 목표

홈 화면의 오늘 방문자 수에 더하는 고정 보정값 `40`을 한국 날짜별로 결정되는 `10~40` 범위의 기본값으로 교체한다. 같은 한국 날짜에는 서버 인스턴스나 요청 횟수와 관계없이 동일한 값을 표시하고, 날짜가 바뀌면 새 값을 계산한다.

## 동작

- `Asia/Seoul` 시간대의 현재 날짜를 `YYYY-MM-DD` 형태로 구한다.
- 날짜 문자열을 결정적 해시 함수에 입력하고 결과를 `10~40` 범위로 매핑한다.
- 표시값은 `GA4의 실제 오늘 방문자 수 + 날짜별 기본값`이다.
- GA4 자격증명이 없거나 조회가 실패해도 날짜별 기본값은 표시한다.
- 기존 `ANALYTICS_DAILY_CALIBRATION` 환경변수는 사용하지 않는다.

## 구현 경계

- 날짜별 기본값 계산을 부작용 없는 작은 함수로 분리한다.
- 외부 저장소, 데이터베이스, KV, 런타임 랜덤값은 추가하지 않는다.
- 전체 조회수 보정값과 인기 글·페이지 조회수 기능은 변경하지 않는다.
- 기존 1시간 캐시는 유지한다. 날짜 계산은 통계 조회 시 수행한다.

## 검증

- 동일한 한국 날짜는 항상 동일한 값을 반환한다.
- 결과는 양 끝을 포함해 `10~40` 범위에 있다.
- 서로 다른 날짜 표본에서 날짜별 값이 달라질 수 있음을 확인한다.
- 실제 방문자 수에 날짜별 기본값이 더해진다.
- GA4 클라이언트가 없거나 조회가 실패하면 날짜별 기본값이 반환된다.
- 관련 단위 테스트와 프로젝트 정적 검사를 통과한다.
